# Handoff — premise-diversity v6 (for the next agent)

Context for whoever picks this up. This documents a session of work on the
`mmmu-pro-premise-diversity` branch of `theostoican/eidos`.

## What this experiment is

Does **nucleus-sampling diversity predict correctness** when Qwen3.5-9B reads a single
**visual premise** off an MMMU-Pro question? 24 questions (one per subject, all baseline
*failures*), swept over 5 `top_p` ∈ {0.5,0.7,0.9,0.95,1.0} × 16 samples (thinking ON,
4096-token cap). Per (example, top_p) cell we measure **diversity** (Vendi score + mean
pairwise cosine distance over MiniLM embeddings) vs **correctness** (fraction of premises
judged true against the image).

## What changed this session (in order)

1. **Truncation cleanup.** The 232/1920 generations that hit the 4096 cap before emitting a
   `Premise:` line (`finish_reason='length'`) were removed from **every** artifact (premises,
   verdicts, report, judge packets, index, plot), keeping all 24 questions → **1688 samples**.
   The old raw/`_clean` split was consolidated: `*_clean*` duplicates deleted, the canonical
   files are now the truncation-free ones.

2. **`extract_premises.py` (new).** The step that parses the `Premise:` line out of the raw
   generation was missing from the repo. Added it; rule = text after the **last** `Premise:`,
   first line only (`""` if absent). Reproduces the committed `judge_v6/*.compact.json` exactly
   (0 mismatches on all 1920 originals). Writes `outputs/premises_v6_extracted.jsonl`. In the
   clean set, every row has a premise (the 87 premise-less rows were all truncated → removed).

3. **Diversity embedding → extracted premise.** `premise_analyze.py` now embeds the extracted
   premise (`premise_text()`), not the full `<think>` trace. Was the post-`</think>` tail.

4. **Judge re-run on the extracted premise.** `judge_prep.py` now feeds **premise-only** text to
   the judge (packet `text` == `compact.premise`). The verdicts were regenerated by an
   **LLM vision judge = Claude** (the agent acting as judge, fanned out one image per sub-agent,
   strict rubric: true = accurate reading of the image, false = misread value/label/location/
   identity/relation; gold answer used as the ground-truth anchor). New `verdicts_v6.jsonl` +
   `judge_v6/*.verdicts.json`. **NOTE:** the original verdicts were produced by some other (not
   committed) judge over the *full* generation — so these numbers reflect a **different judge
   (Claude) and a different input (premise only)**, not directly comparable to any prior run.
   There is still **no committed judge model/prompt script**; re-judging means re-running a
   vision judge over `judge_v6/<id>.json`.

5. **Re-analysis + figures + notebook.** Re-ran `premise_analyze.py` → `premise_report_v6.json`,
   regenerated `outputs/harmonic_per_example_premise_v6.png`, and re-executed
   `analysis_v6.ipynb` (embedded data + prose + 3 figures all refreshed). README updated.

## Final results (premise-judged, truncation-free)

- Overall premise accuracy **85.6%** (1445/1688). 10/24 questions all-correct at every top_p.
- **vendi ↔ correct: Pearson −0.32, Spearman −0.49** (all 24Q); **−0.56** dropping the 3
  image-hallucination questions (Basic_Medical_Science_209 .08, Biology_132 .24,
  Diagnostics_116 .54 — low diversity *and* low correctness, so they sit off the trend).
- **top_p ↔ correctness ≈ 0** (−0.07): correctness drifts 0.861→0.811 as top_p 0.5→1.0;
  diversity (Vendi) rises 2.40→3.09.
- **Optimal top_p:** ~**0.7** (correctness-leaning: most diversity gained for ~0 correctness
  cost) or **0.95** (formal balance optimum on min-max-normalized correctness×diversity;
  0.9 is strictly dominated by 0.95). Avoid 1.0.
- Wrong premises (243 total) concentrate in 14 questions; two are wrong at *every* top_p
  (Biology, Basic_Medical = systematic hallucination), several only degrade at high top_p
  (Diagnostics: 0/16 wrong at 0.5 → ~10 at 0.9–1.0; Design; Art).
